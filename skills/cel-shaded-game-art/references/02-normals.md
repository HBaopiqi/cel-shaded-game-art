# 法线与阴影

来源：M pp. 60-84；O pp. 56-62。书目见 [来源索引](00-sources.md)。

## 1. 先确认要改变的是什么

**适用**：几何剪影已经正确，明暗分界却脏乱或偏离设计。法线控制受光方向，不直接改变真实剪影，也不等于修改投射阴影轮廓。不要用法线掩盖本来就错误的体块。

法线可由相邻面的几何关系和软件计算规则产生，也可显式编辑。实际数据常是面角/拆分顶点法线，而不一定每个共享几何顶点只有一根方向；实现时以目标格式为准（后一句为工程澄清）。

## 2. 选择三类控制（M pp. 66-79）

### 几何/拓扑控制自动法线（pp. 68-71）

用边与支持顶点影响自动法线及阴影分布，适用于衣边、臂环、盒形部件和发梢。新增顶点即使不改剪影，也可承担着色控制功能；明确新增目的和预算，不把“越少面越好”或“加面一定更平滑”当结论。

**验证**：锁定光源与镜头对照。检查硬边/平滑组、加权法线算法和三角化变化，不能假定所有 DCC 自动法线结果一致。

### 从辅助表面传递法线（pp. 72-75）

从球状或更平顺的代理表面传递方向，用于头发、草木面片等整体柔和受光。它适合大范围趋势，通常不能独立提供精确的面部阴影边界。法线传递只是法线编辑的一种方式。

**验证**：查看代理表面覆盖和匹配方式，检查薄片背面、缝隙与边界；删掉/隐藏代理后，目标数据仍应保留。

### 关键区域手调（pp. 76-79）

对需要特定阴影的面部等局部逐点调整；与前两法混用，不必手改全身。先按期望的明暗变化规划足够的采样顶点/边流，缺少控制点时只改现有法线不可能表达任意高精度边界。

**边界**：着色器阈值、插值和光向都会影响边界，不能把“某处没有顶点”绝对化为“此处不可能出现任何明暗边界”。

## 3. 四项联动风险（M pp. 80-84；O pp. 56-62）

1. **背面法描边**：为光影设计的法线未必适合外扩。硬边会让外壳裂开，球形化法线也可能使该出的局部线消失。用独立挤出方向解决，见 [描边工程](06-outline-engineering.md)。
2. **骨骼/表情**：法线会随形变改变；静态脸干净不代表旋转面部骨骼、张嘴或夸张表情后仍然干净。
3. **细分、拓扑编辑和重算法线**：可能重建/覆盖手工数据。资料描述了其原管线限制；当前工具是否可保留，必须验证，不写成“所有细分永远不兼容”。
4. **导出/导入**：记录法线来源和保留策略；导入时重算可能抹掉美术编辑。不要只凭 DCC 截图断言引擎一致。

## 4. 验证步骤（工程建议）

- 固定基准：同一网格、镜头、光向和材质参数下比较自动、传递、手调版本。
- 转动主光源并检查项目允许的所有光照条件；若只针对固定光源设计，明确限制。
- 播放表情和关键姿势，检查脸颊、眼窝、发梢、接缝、硬边和薄片。
- 导出再导入，核对法线、切线、顶点色和三角化；分别观察本体与描边，避免两个错误互相掩盖。
- 记录修正前后截图与未覆盖的情况；没有目标引擎时仅报告 DCC/静态审查状态。
