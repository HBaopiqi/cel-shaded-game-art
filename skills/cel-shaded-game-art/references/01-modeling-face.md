# 造型与面部

来源：M pp. 7-59、86-87。M 为《卡通风格角色建模TIPS》；完整书目见 [来源索引](00-sources.md)。

## 1. 从目标画面反推模型（M pp. 7-21）

**适用**：将 2D 角色转成可动画的 3D，或模型细节很多却不像原画时。

- 先对齐大剪影、头身比、躯干与四肢比例、重心和识别性部件，再细化。头部仅小幅变化也可能改变年龄感；资料中的 5% 是展示敏感性的例子，不是调参标准。
- 选择最常用或最能代表角色、且比例易读的构图；强透视和大仰俯角不宜作为唯一比例依据。不要依赖互相矛盾的正侧视图作为绝对真值。在同一视口中放参考图，与模型并排或叠加检查，并先统一画面占比。
- 可以从素体调整，也可以从零搭建；重点是观察原画为什么成立，不是逐点机械描线。
- 早放简骨、做临时蒙皮并摆到原画姿势。早期尽量以基础网格比例和关节旋转成立，不用特殊伸缩遮盖比例问题。默认 A/T 姿势掩盖的手脚长度和肩髋比例，往往在角色姿态中才暴露。
- 反复走“参考姿态 → 比例修改 → 主镜头与其他镜头复验”，不要等完成细节才第一次摆姿势。

**验证**：至少保存同镜头、同构图的原画/模型对照，以及目标游戏视角和两种关键姿态；在实际显示尺寸下确认角色识别是否保持。多角度/显示尺寸检查是本包的工程建议。

## 2. 风格化面部不存在无代价的单一三维解（M pp. 23-31、58-59）

- 先确定必须成立的镜头。二维脸的夸张和省略会使多视角相互冲突，不要用写实解剖抹掉设计特色，也不要承诺任意角度零变形。
- 对常见动漫脸优先让三分之四侧面成立，再复验正面、侧面、仰俯视。若作品主要从其他角度观察，以其真实镜头优先级替代，不强推三分之四为所有作品主视角。
- 基础体块尽量稳健；必要时为特定镜头/表情做骨骼或变形目标修正。明确修正的触发范围，避免一个镜头的补丁破坏另一个。

## 3. 四个关键形体问题（M pp. 32-57）

### 脸颊线（pp. 33-35）

三分之四角度的脸颊转折是独立设计对象，能决定柔和、锐利或厚重感；仅从正面和正侧面推挤无法可靠决定这条线。

**检查**：看额面到颧/颊再到嘴和下颌的连接，不让拓扑均匀性取代目标剪影。

### 嘴角后收（pp. 36-39）

在适合此类风格的嘴型中，让嘴角向后、向内收进面部体积，而不是把“嘴唇符号”贴在前方平面上。嘴角保留必要的局部宽度和厚度，不把所有边汇成零厚度尖点。闭嘴好看仍须测试张嘴，检查口腔开口是否突兀、嘴角是否外翻。

**边界**：不是所有角色都要同样的后收量；按原画的嘴型和表情选用，不直接套写实嘴唇。

### 眉眼纵深与远侧眼（pp. 40-47）

内眼角至眉心/额头的深度关系影响眉眼立体感。若要让三分之四视角的远侧眼更窄，优先调整外眼角向后的体积关系，不要简单旋转整块眼部面片：后者可能使正侧面看到不该暴露的内眼白，并在仰视时显得下垂或失焦。

**检查**：正面、左右三分之四、正侧面、仰视与俯视下比较眼宽、嵌入感和眼眶过渡；两侧都测，不仅测原画朝向。

### 将正脸宽度与下颌线拆开（pp. 48-57）

斜看带厚度的脸会增宽。如果正侧面都对、斜脸却宽，不要直接压扁整个头或把正面收窄。先区分较前方决定正脸最大宽度的转折与更靠后的下颌轮廓，再独立调整下颌横向宽度，使斜脸更集中。

**检查**：改动前后使用相同视角对照；正面与侧面不应被无意破坏。这里是特定风格的建模思路，不是所有头型都必须建立可见硬棱。

## 4. 交接

记录关键镜头、允许的镜头依赖修正、参考姿态、未解决的侧脸/表情问题。结合绑定、着色与动画理解造型，单角度临摹不能代替独立立体角色的完整表现。对造型之外的脏影转读 [法线与阴影](02-normals.md)，对摆姿势后失形转读 [拓扑与蒙皮](03-topology-skinning.md)。
