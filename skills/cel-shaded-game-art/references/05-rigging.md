# 绑定与辅助骨

来源：R pp. 7-55；S pp. 37-42。书目见 [来源索引](00-sources.md)。

## 1. 先区分三层（R pp. 7-18）

- 网格承载形体，骨骼变换驱动网格，控制器帮助动画师有效操作。Rig 不等于刷权重。
- 常见 DCC 控制器 → 骨骼 → 网格的关系，不意味着这些控制器和约束会随文件原样在引擎中运行。通常交付网格、骨骼及烘焙的动画；确需运行时绑定则另定目标实现。
- 可复用骨架参数来适应长度、肩宽、髋宽；角色独有的发束、衣摆、装饰和表情结构另配。共用的是控制逻辑，不是所有角色的数值和骨骼数量。
- 资料的手调关键帧与大量局部骨骼来自格斗演出需求；低成本角色只保留实际可见且需要运动的部件，简单附属物可用 FK。
- 为艺术表现允许适当伸缩、弧线、局部放大，但不要将不必要的复杂机制当作质量指标。

## 2. 缩放必须作为独立风险测试（R pp. 16-18）

串联父子链中的非等比缩放与旋转组合，可能造成继承畸变、剪切或 DCC/引擎不一致。原案例采用特殊并联结构，并对等比缩放或末端非等比缩放作约束。

**操作**：先确认目标需要什么变形；画清驱动层与导出骨架的父子关系；用一段带父子旋转和缩放的最小动画做往返验证。等比或末端限制是可选规避策略，不是跨所有引擎的保证。

## 3. 约束基础（R pp. 19-31）

- **FK**：从父级到子级逐级摆姿势。**IK**：以末端目标解算中间关节。选择依据是动画师任务和姿态控制，不作高低优劣排序。
- **位置约束**：控制平移，不自动匹配旋转。
- **旋转约束**：匹配目标姿态，不等同于“看向目标的位置”；不同软件用 Orient/Orientation 等名称。
- **Aim / LookAt / Direction**：让某条局部轴指向目标点。只有这条方向仍留下绕轴滚转自由度，需要 Up Vector 或其他次轴参照来决定滚转。
- **位置+旋转**：可组成道具跟随；对多个目标的权重打关键帧可实现拿起、换手、放下。切换前对齐偏移，检查是否跳变，这是本包工程建议。
- 检查 Aim 轴、Up 轴、空间、偏移和父级继承；主方向与 Up 近共线等退化位置必须测试。不能把一个 Up Vector 设置理解为永久无翻转。

## 4. 半旋转辅助骨（R pp. 34-37）

**适用**：髋、膝等大角度折叠中，已排查轴心和拓扑，仍需要局部保体积。

1. 在相邻变形骨之间设辅助驱动，使其姿态从两骨旋转得到中间状态。原例使用等权旋转约束。
2. 将需要保留体积的局部顶点适量分配给辅助骨，比较折叠前、中段、最大角度的形体。
3. 调整位置、旋转混合与权重范围，防止静止鼓包或中段突变。

**关键区别**：平均骨骼旋转后再变形，不等同于把原来的两个骨骼对顶点各赋 50%。单轴“转一半”的直观图解不能替代三维旋转求值。

**翻转风险**：多目标旋转混合可能跨越奇异/不连续区域。原演示提到 Softimage 的 Pose 旋转通道、Maya 的 Shortest 插值，以及 3ds Max 需其他控制方式；这些是历史示例，不是当前版本支持保证。实际先核对目标软件官方文档，再测试正负极限、跨轴旋转、逐帧播放与回放。最短路径也不能自动证明全动画连续。

## 5. 前臂扭转分配（R pp. 38-42；S pp. 39-41）

**适用**：手掌转动集中在腕部，出现突兀折痕或扭拧。

1. 明确前臂的长轴与基准空间，分离沿轴扭转和其他摆动。
2. 原例在前臂下放扭转骨，朝向肘部；在手掌子级、大拇指/手背侧设置 Up 参照，使其滚转跟随手掌。
3. 沿前臂放附加扭转骨，在提取出的扭转姿态与前臂基准之间渐变混合；越近肘通常分到越少的腕部扭转。
4. 图中的中段 50/50、近肘 20/80 用于说明梯度，不是默认权重表。数量、位置和比例由轮廓与性能决定。

**验证**：纯旋腕、屈肘后旋腕、抬臂同时旋腕、正反向连续转动；检查肘部是否跟着错误转动、Aim/Up 退化、截面塌陷及边缘缝隙。若采用四元数分解、表达式或节点替代，保留相同可观察目标，不必照搬原约束网络。

## 6. 髋部局部防凹陷（R pp. 43-52）

**适用**：跨步或高抬腿时，髋侧折叠区形成明显凹洞，单靠原两骨权重和小幅拓扑调整不能满足目标。

1. 从腰作为大腿父级的结构起步，让辅助骨与大腿骨共享同一初始空间起点，作为腰部子级。
2. 将上方目标 A 挂在腰部、下方目标 B 挂在大腿，沿原示例方向以等距的上下布局夹住辅助骨初始点，使静止中点与之重合。
3. 用 A/B 各 50% 的位置约束求中点；大腿带 B 运动后，中点产生局部外撑位移。
4. 再以各 50% 混合 A/B 的旋转，给凹陷区域适量辅助骨权重，调至与目标体积一致。

**边界**：目标布局决定外撑方向，不能随机放 A/B 就期待相同结果；改变初始位置或目标布局属于需要另行验证的变体。修的是局部折叠区，不是整体放大大腿。半旋转与防凹陷可能有重叠效果，需要分别开关比较，避免双重补偿鼓包。

**验证**：前抬腿、侧抬腿、交叉腿、回到静止和连续过渡；检查辅助骨方向、静止偏移、臀部体积、衣层穿插与动画导出。

## 7. 实现与交付（R pp. 53-55）

约束、表达式、驱动关键帧或节点均可实现驱动目标，按维护性、实时成本和导出支持选择。交接时说明哪些结果已烘焙、哪些必须运行时求值、控制器与导出骨架的区别，以及尚未测试的缩放、旋转范围。参见 [验证与交付](08-validation-handoff.md)。
