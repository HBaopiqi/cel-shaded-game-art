# 三渲二角色制作

用户说「做一个三渲二角色」就足以开始。按角色的用途、目标镜头和动作选择当前会用到的经验。项目已确定三渲二画风时，后续局部修改和提问沿用该上下文。使用提问者的语言回答。

- **制作或修改模型**时，在用户选定的软件中落实相关做法。用户让你用 Blender 做角色，且当前环境已能操作 Blender 时，就使用已有工具创建或编辑模型。先在目标镜头下定剪影，再用一个代表动作检查低模和临时骨架。例如角色要举剑，就在细化肩部和衣袖前先试抬臂，按结果调整轴心或布线。做到着色时，再分别检查本体的明暗和描边。只在手头有描述或截图时，给出能在模型副本上执行的步骤，标明待验证的结果。
- **回答制作问题**时，先回答用户问的具体选择，再指出会影响这个选择的关联细节和一个验证办法。例如用户问「头发能用球面传递法线吗」，先解释它对受光的作用。如果角色用背面法描边，再提醒检查发梢的外扩方向是否也读取了这套法线。[法线与阴影](references/02-normals.md) · [描边工程](references/06-outline-engineering.md)
- **评审或排错**时，先说明从原画、截图、模型或日志中实际看到的现象。给出一个能区分最可能原因的对照实验，以及两种结果各自指向的下一步。如果手头只有描述，就把原因写成待验证的假设。
- **交接资产**时，确认 DCC、引擎版本、渲染管线和已占用的数据通道。记录工程里实际验证过的姿势、画面和导入结果。对没有工具或资产可查的环节，给出读者能执行的最小复验。

## 按现象查阅

制作时打开与当前决定对应的主题，排错时从出现问题的镜头或动作帧开始。同一镜头下每次改变一个变量，按结果决定是否需要查相邻环节。

| 现象或目标 | 先看哪里 |
| --- | --- |
| 原画转模型、三分之四侧脸偏宽、远侧眼或嘴角失形 | [造型与面部](references/01-modeling-face.md) |
| 剪影稳定，但明暗分界脏，做表情或细分后受光变化 | [法线与阴影](references/02-normals.md) |
| 膝肘深弯变细、两层服装穿插、刷权重无效 | [拓扑与蒙皮](references/03-topology-skinning.md) |
| 站姿成立，抬腿、握拳或蹬地时比例和轴心不对 | [骨骼放置](references/04-bone-placement.md) |
| 手腕扭拧、约束翻转、髋侧在抬腿时凹陷 | [绑定与辅助骨](references/05-rigging.md) |
| 描边在硬边处分裂、变焦时粗细跳变、切线通道冲突 | [描边工程](references/06-outline-engineering.md) |
| 衣褶浮线、袖口收线、面部内线太密或主动出线 | [描边美术控制](references/07-outline-art.md) |
| 导入引擎才出问题、需要动作测试或资产交接 | [验证与交付](references/08-validation-handoff.md) |

## 跨环节的判断

- 两根骨骼做线性混合蒙皮（LBS）时，一个顶点的两个极端位置决定了调权重可到达的线段。目标在段外时，比较轴心、拓扑或辅助骨。辅助骨的旋转插值与原两骨各占一半权重会得到不同轨迹。
- 艺术调整过的光照法线和描边外扩方向各有用途。借用切线前，检查法线贴图、导入器和蒙皮如何读写切线。若方向存进顶点色或 UV，需要约定如何随骨骼变换。线宽、深度与顶点色 A/B 的对应关系仅适用于采用该约定的项目。
- 原例的镜头、类人比例、约束和特制渲染管线决定了适用范围。非人形角色按自身动作裁剪。依赖具体版本的设置，核对目标软件的文档，并用资产副本试验。
