# 三渲二角色制作

从角色在哪个镜头、哪个动作帧失去预期效果开始。保持相机、姿势和材质一致，每次只改变一个会影响判断的变量。使用提问者的语言回答。

- **做新角色**时，先确定必须成立的剪影和动作。在低模阶段放入临时骨架，摆出代表姿势，再决定哪些部位需要加面、控法线或加辅助骨。
- **评审或排错**时，先说明从原画、截图、模型或日志中实际看到的现象。给出一个能区分最可能原因的对照实验，以及两种结果各自指向的下一步。如果手头只有描述，就把原因写成待验证的假设。
- **交接资产**时，确认 DCC、引擎版本、渲染管线和已占用的数据通道。记录工程里实际验证过的姿势、画面和导入结果。对没有工具或资产可查的环节，给出读者能执行的最小复验。

## 跨环节的判断

- 两根骨骼做线性混合蒙皮（LBS）时，一个顶点的两个极端位置决定了调权重可到达的线段。目标在段外时，比较轴心、拓扑或辅助骨。辅助骨的旋转插值与原两骨各占一半权重会得到不同轨迹。
- 艺术调整过的光照法线和描边外扩方向各有用途。借用切线前，检查法线贴图、导入器和蒙皮如何读写切线。若方向存进顶点色或 UV，需要约定如何随骨骼变换。线宽、深度与顶点色 A/B 的对应关系仅适用于采用该约定的项目。
- 原例的镜头、类人比例、约束和特制渲染管线决定了适用范围。非人形角色按自身动作裁剪。依赖具体版本的设置，核对目标软件的文档，并用资产副本试验。
