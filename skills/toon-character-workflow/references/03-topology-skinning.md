# 拓扑与蒙皮

来源：S pp. 7-42；B pp. 7-15、58；R pp. 34-52。书目见 [来源索引](00-sources.md)。

## 1. 从易操作、能弯曲的模型开始（S pp. 7-11）

- A-pose 与 T-pose 都可选，依据角色和制作环节决定；让需要赋权的区域容易选取，不强制一种默认姿势。
- 合理拆分非连续零件，减少纠缠。拆分是编辑组织策略，不代表交付时必须永远拆成多个 draw call。
- 将需要同一权重或渐变权重的顶点排得便于选择；网格行列服务于动作，不机械追求全身均匀四边形。

## 2. 正确诊断“50% 权重陷阱”（S pp. 13-23）

**适用前提**：关注的是线性混合蒙皮 LBS 下，同一顶点受两个骨骼变换结果的线性组合，而非所有蒙皮算法和所有拓扑。

设顶点分别由骨骼 A、B 完全控制时的形变后位置为 pA、pB，则两个权重归一化时有 p = (1-w)pA + w pB。50/50 产生的是两位置间的直线中点，不是沿关节圆弧运动一半。将 w 改为 25/75 只把点移到同一线段的另一处；如果期望的轮廓在这条线段之外，反复刷这两个权重无法到达。

**最小实验**：保存问题姿势，分别临时设该点 A=100% 和 B=100%，观察两端点与目标位置。不要直接把实验覆盖到正式资产；使用副本或可撤销修改。

**避免误读**：50% 不是禁用值，也不是所有关节必然塌陷。问题是当前几何、轴心、姿态与 LBS 的组合。盲目加分段或把权重刷得更平滑可能扩大塌陷区。

## 3. 两类关节布线（S pp. 24-28）

### 折叠/局部重叠型

将顶点避开容易产生不理想中间插值的折弯区，使内侧随弯曲收拢、局部嵌入，优先保持外侧体积和剪影。

**适用**：允许内部局部重叠、镜头看不到问题接缝的实时低模关节。不是对任何穿模的通行证；外露穿插、透明材质、厚度或碰撞要求另验。

### 外张/梯形型

让弯曲区在默认形态具有适当外张余量，使弯曲时不轻易被拉进内侧。开口量、边间距和权重必须通过目标姿势决定；过量可能鼓包，不承诺“必不塌”。

### 共同原则

在外侧拉伸区保留必要采样；内侧收缩区不要盲目堆环线。从弯曲后的目标形态反推默认布线，而不是把默认网格最平整当唯一目标。

## 4. 骨骼与网格一起调（S pp. 29-33）

- 在建模时就区分刚性区与变形区。部分低模可以用接近刚性的赋权得到清晰动作，但不要把 100% 权重变成全身规则。
- 权重怎么改都不对时检查轴心；先用旋转工具的 pivot 试弯，不必等完整绑定。
- 若临时平移网格后试弯变好，可撤销网格位移，再把骨骼往反方向移动相同距离，验证相对位置假设。只在副本中测试，并复验其他姿势和绑定初始矩阵。
- 轴心问题转读 [骨骼放置](04-bone-placement.md)，体积问题仍存在时转读 [绑定与辅助骨](05-rigging.md)。

## 5. 多层衣物和实际动作（S pp. 34-42）

内外层对应区域的拓扑采样与权重应协调。贴身衣物和身体即使默认姿势不穿，也会因变形差异而相交。对相同动作轨迹的贴合层尽量匹配；故意独立运动的外衣需要自己的驱动方案，不机械复制权重。

在模型尚粗糙时就检查深蹲、抬腿、侧跨、肩部抬落、肘弯、腕扭等实际需要的动作。若单一骨架不能表现前臂逐渐扭转，加入分段扭转骨并逐步分配旋转，而非把全部扭转压在手腕。

## 6. 通过条件

在项目真实镜头与极限姿态下：外轮廓可读、体积变化符合设计、关节无意外折痕、外层不产生明显穿插。记录允许的艺术性重叠、动作范围和测试帧。辅助骨改善静态图不等于动画连续性通过，仍须检查过渡和导出。
